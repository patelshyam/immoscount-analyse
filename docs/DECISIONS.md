| 1   | 0     | City→state map covers all German cities with **≥20,000** inhabitants (spec: ≥100,000).                                                                              | Owner's request (2026-10-04). | 8   | 0     | Single `.env` at repo root; `next.config.ts` and `prisma.config.ts` load it via `process.loadEnvFile` when present.                                                 | One env file for compose and local dev.                                                                                                                            |
