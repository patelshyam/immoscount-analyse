# Decisions & deviations from SPEC.md

| #   | Phase | Decision                                                                                                                                                                                                                                                                                                                         | Reason                                                                                                                                                             |
| --- | ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 0     | City→state map covers all German cities with **≥20,000** inhabitants (spec: ≥100,000).                                                                                                                                                                                                                                           | Owner's request (2026-10-04). Source: Wikipedia "Liste der Groß- und Mittelstädte in Deutschland", pulled once at dev time.                                        |
| 2   | 0     | **TypeScript 6.0.3**, not `latest` 7.0.2.                                                                                                                                                                                                                                                                                        | typescript-eslint 8.71.0 peer range is `<6.1.0`.                                                                                                                   |
| 3   | 0     | **Prisma 7.10.0**, not npm `latest` (8.0.0-rc.19).                                                                                                                                                                                                                                                                               | `latest` points to a release candidate; 7.10.0 is the newest stable.                                                                                               |
| 4   | 0     | **ESLint 9.39.5**, not 10.x.                                                                                                                                                                                                                                                                                                     | `eslint-config-next` 16.3.8 pulls eslint-plugin-react/import/jsx-a11y whose peer ranges stop at ESLint 9.                                                          |
| 5   | 0     | Seed runs in Next.js `instrumentation.ts` on server start (idempotent), not as a separate entrypoint step. Entrypoint = `prisma migrate deploy` → `node server.js`.                                                                                                                                                              | Standalone output has no `tsx`/dev deps; running the seed inside the already-bundled server avoids shipping a second `node_modules`. Same code path in `pnpm dev`. |
| 6   | 0     | Prisma CLI for `migrate deploy` is installed in its own stage (`/opt/prisma`) in the image.                                                                                                                                                                                                                                      | Standalone output doesn't include the CLI.                                                                                                                         |
| 7   | 0     | Host ports are configurable (`DB_HOST_PORT`, `APP_HOST_PORT`, defaults 5432/3000), still bound to `127.0.0.1`.                                                                                                                                                                                                                   | Other local projects already use 5432/3000 on the dev machine.                                                                                                     |
| 8   | 0     | Single `.env` at repo root; `next.config.ts` and `prisma.config.ts` load it via `process.loadEnvFile` when present.                                                                                                                                                                                                              | One env file for compose and local dev.                                                                                                                            |
| 9   | 0     | Extension panel will use **React** (not Preact); no `@types/chrome` (WXT ships browser types).                                                                                                                                                                                                                                   | Same framework as the web app; bundle size irrelevant on localhost.                                                                                                |
| 10  | 0     | Transfer-tax rows have `verifiedOn: null` and `source: "SPEC.md §5b.1 (to be re-verified)"`.                                                                                                                                                                                                                                     | Rates come from the spec, not independently verified.                                                                                                              |
| 11  | 1     | City→state data: 704 cities from Wikipedia (revision recorded in `city-state.json`), plus short aliases ("Frankfurt am Main" → "frankfurt"). Any key that maps to more than one state is dropped — e.g. `senden` (BY/NW), `frankfurt` (HE/BB), `halle` (ST/NW) — so the extension asks instead of guessing a wrong transfer tax. | Silent wrong state = wrong Grunderwerbsteuer.                                                                                                                      |
| 12  | 1     | City keys keep the qualifier as words: "Halle (Saale)" → `halle saale` (not stripped).                                                                                                                                                                                                                                           | Stripping "(Saale)" / "(Oder)" made distinct cities collide.                                                                                                       |
| 13  | 1     | Demo rent rows: flat **10 €/m²** for all 5 size bands in Berlin, Frankfurt am Main and Leipzig, `source = DEMO PLACEHOLDER`, `isPlaceholder = true`. Seeded only into an empty table.                                                                                                                                            | Obviously fake values so the UI works; no invented market data.                                                                                                    |
| 14  | 1     | A rent of **0** (override or actual) is treated as missing and falls through to the next source.                                                                                                                                                                                                                                 | A 0 € Kaltmiete is almost always a parse/entry gap, not a real rent.                                                                                               |
| 15  | 1     | Hausgeld only applies to `apartment`; `house` and `multi_family` use Hnr = 0.                                                                                                                                                                                                                                                    | SPEC §5.3 "houses: 0"; a whole multi-family building has no WEG Hausgeld either.                                                                                   |
| 16  | 1     | `parseGermanNumber` lives in `@immo/calc` (pure, zero deps) and is shared by the web forms and the extension.                                                                                                                                                                                                                    | One implementation, one test suite. Without a comma, a dot is only a thousands separator in `1.234.567` form, so `3.5` stays 3.5.                                  |
| 17  | 1     | `/api/calculate` fills a missing `state` from the CityState table.                                                                                                                                                                                                                                                               | Calculator works with just a city name.                                                                                                                            |
| 18  | 1     | `RentReference` has no `state` column (SPEC §7.3); the CSV `state` column is informational.                                                                                                                                                                                                                                      | Matches the spec's data model; matching is by city.                                                                                                                |
| 19  | 2     | `fmtEur`/`fmtPct`/`fmtNum` (de-DE) live in `@immo/calc` and are shared by web and extension.                                                                                                                                                                                                                                     | Same formatting everywhere; display-only, calc math stays unrounded.                                                                                               |
| 20  | 2     | `apiFetch` (`apps/extension/src/api.ts`) is the extension's only network code and refuses any host other than `127.0.0.1`/`localhost` over http. A test scans the sources for other `fetch`/XHR/WebSocket use.                                                                                                                   | Makes "no requests to the portals" a structural guarantee, not a convention.                                                                                       |
| 21  | 2     | Panel styles are plain CSS (`panel.css`) injected into the Shadow DOM via WXT `cssInjectionMode: 'ui'`, not Tailwind.                                                                                                                                                                                                            | One small stylesheet; no build-time CSS framework in the content script.                                                                                           |
| 22  | 2     | The bootstrap-refresh "every 10 minutes" (Phase 3) will be "on startup + when the cached copy is older than 10 minutes on next use".                                                                                                                                                                                             | An MV3 service worker can't keep timers alive and `alarms` would be an extra permission (SPEC §6.1).                                                               |
